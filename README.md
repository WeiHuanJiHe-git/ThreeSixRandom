# ThreeSixRandom / 三数六宫 v1.5.0

离线 Android 三数连续起宫工具。

## v1.5.0
- 每次停止后自动写入历史记录，默认名称为时间。
- 独立“保存”按钮：点击后必须命名，并在历史记录中显示 ★ 主动保存标记。
- 保存操作不会触发重新摇数。
- 点击空白区域：滚动时停止并定数；停止后再次点击则重新摇数。
- 历史记录点击可查看当次数字、三宫、时间和完整解读。
- 内置六宫传统原文。
- 三宫解释按：前态 / 事中 / 结果。
- 6×6×6 共 216 种组合全部离线覆盖。
- 保留 SecureRandom + 触摸时刻/坐标混入种子的随机逻辑。

## GitHub Actions 构建
Actions -> Build Android APK -> Run workflow。
构建成功后，在该次 Workflow 的 Artifacts 下载 `ThreeSixRandom-v1.5.0-apk`。

传统原文据《玉匣记·杂占篇·李淳风六壬时课》通行本整理。现代三阶段解释仅作传统文化参考。
